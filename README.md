# Pixel-Camping-Exploration-Collection-Mini-Game
瓦片地图
瓦片尺寸：32px；地图宽25格，高18格
瓦片类型：草地(可通行)、树木(障碍)、岩石(障碍)、篝火(固定点位，夜晚发光粒子)
拾取物：柴禾、水壶，随机在草地刷新；拾取后消失，30秒后在随机草地重新刷新
玩家控制
WASD / 上下方向键控制移动；移动速度 3px/帧
碰撞检测：碰到障碍瓦片停止移动，不能穿树穿石头
玩家是简单像素小人，4方向静态帧即可，不需要复杂动画
昼夜循环系统（重点） 一轮完整昼夜：120游戏秒 040s：白天，画面亮度正常，绿色草地，无星空，篝火无发光 4060s：黄昏，画面叠加橙色蒙版，逐步变暗 60100s：夜晚，深蓝色蒙版，绘制像素星空点阵，篝火开启暖黄色粒子向上飘散动画 100120s：黎明，蒙版逐步褪去，回到白天 画布全局用rgba叠加蒙版实现色调变化，不要换图

拾取&抽卡流程 玩家坐标和拾取物坐标重叠 → 自动拾取 → 触发随机抽卡 → 弹出像素风格翻卡弹窗，展示抽到卡牌； → 判断是否是新卡牌：新卡牌加入收集列表，更新进度；已经拥有则提示“已经拥有这张卡牌”

图鉴背包系统 快捷键 B：打开图鉴面板；ESC：关闭图鉴面板 图鉴面板结构：

顶部：进度文字【收集：X / 总Y】+ 分类切换标签：全部｜装备｜风景｜小动物
网格布局展示所有卡牌 ✅ 已收集：渲染完整卡牌图，右上角标注稀有度标签（普通绿色/稀有蓝色/传说金色） ❌ 未收集：灰色剪影占位图+像素问号
点击任意卡牌，弹出详情弹窗：卡牌名称、稀有度、分类、露营介绍文案
存档逻辑
首次进入游戏：前端生成随机playerKey存入localStorage
游戏加载：优先请求后端 /api/save 读取存档；后端读取失败时，降级读取localStorage本地存档兜底
每次抽到新卡牌，自动调用POST /api/save同步存档到数据库
